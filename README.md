##COMMONCHER##
Commoncher is a common launcher which can open games and compare game prices among different platforms. Therefore, it can decrease the CPU usage. It might lead to make online shopping with more consciousness. This common launcher can open video games in a single click but it does not mean that it bypass the platforms. When the button is clicked Commoncher calls the platform which has the game. The platforms which have not the game is not used. Thus, the CPU is only dealing with single launcher. To use this launcher you must have downloaded the platforms which do you want to play with. Goals of this MVP are decreasing the CPU usage and making conscious online shopping.
